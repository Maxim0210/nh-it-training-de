Welche AWS-Schulung passt?

Amazon Web Services (AWS) ist die Cloud-Plattform von Amazon. AWS vergibt seine Zertifizierungen selbst und ordnet sie in Stufen: Foundational für das Grundverständnis, darauf aufbauend Associate, Professional und Specialty für bestimmte Rollen und Fachgebiete. Ein AWS-Zertifikat belegt, dass jemand die Prüfung des Herstellers zu diesem Wissensstand bestanden hat. Der Einstieg ist der AWS Certified Cloud Practitioner (Prüfung CLF-C02). Er zeigt, dass Sie Cloud-Begriffe, die wichtigsten AWS-Dienste, Sicherheit und Preismodelle einordnen können, ohne selbst technisch zu arbeiten. Auf dieser Seite finden Sie zwei eintägige Grundlagenkurse und drei dreitägige Vertiefungen, alle auf Deutsch im Format Online Live. Welcher Kurs passt, hängt davon ab, ob Sie AWS verstehen und bewerten oder selbst damit arbeiten wollen.

Überblick für Einsteiger und Entscheider

Wenn Sie AWS fachlich verstehen, Kosten einschätzen oder mit IT-Teams mitreden wollen, beginnen Sie mit AWS Cloud Practitioner Essentials. Der eintägige Kurs behandelt Cloud-Modelle, globale Infrastruktur, Kerndienste, das Modell der geteilten Verantwortung sowie Preise und Support. Er bereitet auf die Prüfung AWS Certified Cloud Practitioner vor.

AWS Cloud Practitioner Essentials

Technischer Einstieg in die AWS-Dienste

Wer AWS selbst einrichten oder betreuen soll, wählt AWS Technical Essentials. In einem Tag arbeiten Sie in Übungen mit der AWS Management Console, IAM, einer eigenen VPC, Amazon S3 und DynamoDB. AWS empfiehlt dafür IT-Erfahrung und Grundwissen zu Servern, Netzwerken und Datenbanken; Cloud-Vorkenntnisse sind nicht nötig.

AWS Technical Essentials

Vertiefung nach Rolle

Nach den Grundlagen geht es je nach Aufgabe weiter: Architecting on AWS für die Planung von Architekturen, Developing on AWS für die Entwicklung von Anwendungen und Systems Operations on AWS für Betrieb, Überwachung und Automatisierung. Diese Kurse dauern jeweils drei Tage. Welcher davon passt, klären Sie am besten in der Beratung.

Quellen: AWS: AWS Certified Cloud Practitioner, AWS: Prüfungspreise und Richtlinien vor der Prüfung, AWS: Rezertifizierung, AWS: Kursbeschreibung Cloud Practitioner Essentials (PDF).

FAQ

Häufige Fragen zum Thema

Welche Prüfung gehört zum Einstieg, und was kostet sie?

Zum Einstieg gehört die Prüfung CLF-C02 für den AWS Certified Cloud Practitioner. Sie dauert 90 Minuten, umfasst 65 Fragen und findet über Pearson VUE im Testcenter oder online beaufsichtigt statt. Die Gebühr beträgt laut AWS 100 USD bzw. 85 EUR, gegebenenfalls zuzüglich Steuern. Sie ist nicht im Kurspreis enthalten. Auf Deutsch bietet AWS diese Prüfung nur noch bis zum 31.12.2026 an.

Welche Voraussetzungen brauche ich?

Für AWS Cloud Practitioner Essentials empfiehlt AWS allgemeines betriebswirtschaftliches IT-Wissen und allgemeine technische IT-Kenntnisse; eine technische Rolle ist nicht nötig. Für AWS Technical Essentials empfiehlt AWS allgemeine IT-Erfahrung und Grundwissen zu Servern, Netzwerken, Datenbanken und Anwendungen. Für die dreitägigen Vertiefungen sind die Grundlagenkurse ein sinnvoller Start.

Wie lange ist ein AWS-Zertifikat gültig?

Der AWS Certified Cloud Practitioner gilt laut AWS drei Jahre. Verlängern können Sie ihn nur, solange er noch gültig ist. Eine Erneuerung verlängert die Gültigkeit um drei Jahre, eine Aufrechterhaltung um ein Jahr. Die genauen Regeln stehen auf der Seite von AWS zur Rezertifizierung.

Kann ich die AWS-Kurse mit Bildungsgutschein besuchen?

Alle AWS-Kurse auf dieser Seite sind für den Bildungsgutschein zugelassen. Ob Sie eine Förderung erhalten, entscheidet die Agentur für Arbeit bzw. das Jobcenter im Einzelfall. Unternehmen können je nach Situation das Qualifizierungschancengesetz nutzen. Ansprechpartner für München, Nürnberg und Stuttgart finden Sie auf der Seite für Arbeitsuchende.
