Welche GitHub-Schulung passt?

Welcher Kurs passt, hängt von Ihrer Aufgabe ab. Wenn Sie Code mit KI-Unterstützung schreiben oder Copilot im Team einführen, ist GitHub Copilot Fundamentals der passende Einstieg. Für CI/CD-Workflows gibt es GitHub Actions and DevOps, für die Verwaltung von Organisationen, Repositories und Rechten GitHub Administration. Bei New Horizons lernen Sie im Live-Online-Training mit Trainer. Für Kunden aus München, Nürnberg und Stuttgart stehen zusätzlich Schulungsräume zur Verfügung. Die Zertifikate gibt GitHub selbst heraus, und zwar für Foundations, Actions, Advanced Security, Administration und Copilot. Jedes Zertifikat belegt Kenntnisse in einem bestimmten Bereich der Plattform. Die Prüfungen sind bei Microsoft Learn aufgeführt und werden dort über Pearson VUE gebucht.

Mit Copilot entwickeln

Sie schreiben Code und möchten GitHub Copilot im Alltag nutzen. GitHub Copilot Fundamentals dauert einen Tag und findet auf Deutsch als Online Live Training statt. Behandelt werden Inline-Vorschläge, Copilot Chat, Agentenmodus, Copilot CLI, Prompt Engineering, Tests und Code-Reviews sowie Datenschutz und Richtlinien. Grundkenntnisse in GitHub und einer Programmiersprache sollten Sie mitbringen.

FAQ

Häufige Fragen zum Thema

Welche Prüfung gehört zum Copilot-Kurs?

GitHub Copilot Fundamentals bereitet auf die Zertifizierung GitHub Copilot mit der Prüfung GH-300 vor. Sie dauert 100 Minuten, wird beaufsichtigt durchgeführt und ist bestanden ab 700 von 900 Punkten. Die Prüfung wird nicht auf Deutsch angeboten, aber zum Beispiel auf Englisch. Die Gebühr nennt der Hersteller bei der Buchung über Pearson VUE. Sie ist nicht im Kurspreis enthalten.

Welche Voraussetzungen brauche ich?

Für die Copilot-Lernpfade setzt Microsoft Grundkenntnisse zu GitHub voraus. Laut Prüfungsbeschreibung GH-300 sollten Sie außerdem Erfahrung mit mindestens einer Programmiersprache haben. Ob Ihr Vorwissen reicht, besprechen wir vor der Anmeldung mit Ihnen.

Wie lange ist ein GitHub-Zertifikat gültig?

GitHub-Zertifikate sind laut Hersteller zwei Jahre gültig. GitHub stellt die Verlängerung auf das Rezertifizierungsverfahren von Microsoft um, damit Zertifikate ohne komplette Wiederholungsprüfung aktiv bleiben können. Den aktuellen Stand finden Sie auf den Zertifizierungsseiten bei Microsoft Learn.

Kann ich eine GitHub-Schulung fördern lassen?

Die Kurse auf dieser Seite sind für den Bildungsgutschein zugelassen. Ob Sie einen Gutschein erhalten, entscheidet die Agentur für Arbeit bzw. das Jobcenter. Für Beschäftigte kann das Qualifizierungschancengesetz infrage kommen. Welche Förderung passt, klären wir mit Ihnen vor der Anmeldung.
