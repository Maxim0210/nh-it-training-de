Python lernen online: Kurs, Einsatzfelder und Förderung

Aktualisiert: 25.11.2026 · Max Dilewski, New Horizons München

Für einen geführten Einstieg in Python eignet sich der zweitägige Kurs Introduction to Python. Sie lernen live mit Trainer online, brauchen keine Python-Vorkenntnisse und schreiben am Ende eigene Skripte für Automatisierung und Datenverarbeitung. Der Kurs ist für den Bildungsgutschein zugelassen. Ob Ihre Teilnahme gefördert wird, entscheidet die Agentur für Arbeit bzw. das Jobcenter.

Wofür setzen Sie Python im Beruf ein?

Python ist eine frei verfügbare Programmiersprache mit einfacher, gut lesbarer Syntax. Im Arbeitsalltag begegnet sie Ihnen vor allem in drei Bereichen.

  • Automatisierung: Dateien umbenennen, Tabellen zusammenführen, Berichte erzeugen oder Inhalte von Webseiten auslesen. Aufgaben, die Sie jede Woche von Hand erledigen, lassen sich oft mit wenigen Zeilen Code wiederholbar machen.
  • Daten: Python liest CSV-, Text- und andere Dateien ein, bereinigt Werte und bereitet sie für Auswertungen oder Reporting-Werkzeuge wie Power BI auf.
  • KI: Viele Bibliotheken für maschinelles Lernen und viele KI-Dienste bieten eine Python-Schnittstelle. Wer Python lesen und schreiben kann, versteht Beispiele und Schnittstellen dieser Werkzeuge deutlich leichter.

Für alle drei Bereiche gilt: Zuerst kommen die Grundlagen der Sprache. Genau dort setzt ein Einstiegskurs an.

Was lernen Sie im Kurs Introduction to Python?

Der Kurs Introduction to Python ist ein eigener Kurs von New Horizons. Er reicht von der Einrichtung der Arbeitsumgebung bis zu ersten praktischen Skripten. Die Inhalte lassen sich in sieben Themenblöcke gliedern:

  1. Arbeitsumgebung: Kommandozeile, Installation von Python und Arbeiten in Jupyter Notebooks
  2. Datentypen und Datenstrukturen
  3. Bedingungen, Schleifen und eigene Funktionen
  4. Fehlersuche, Module und erste Tests
  5. Objektorientierte Programmierung mit Klassen und Objekten
  6. Dateien lesen und schreiben, Dekoratoren und Generatoren
  7. Automatisierung, Web-Scraping und einfache grafische Oberflächen

Nach dem Kurs können Sie einfache Programme schreiben, Fehler im Code finden und kleine Automatisierungen selbst umsetzen. Die vollständige Agenda, aktuelle Termine und den Preis finden Sie auf der Kursseite.

Welche Vorkenntnisse brauchen Sie?

Python-Kenntnisse werden nicht vorausgesetzt. Erwartet werden ein grundlegendes technisches Verständnis und Interesse am Programmieren. Der Kurs richtet sich an Programmiereinsteiger, Fachkräfte mit IT-Bezug und Personen, die mit Daten, Automatisierung oder KI-Anwendungen arbeiten möchten.

Hilfreich ist, wenn Sie sicher mit Dateien und Ordnern umgehen und eine konkrete Aufgabe aus Ihrem Alltag mitbringen. Ein eigenes Beispiel macht die Übungen greifbarer. Wer schon in einer anderen Sprache programmiert hat, findet im offiziellen Python-Tutorial auf docs.python.org eine kostenlose Einführung.

Wie läuft der Python-Kurs online ab?

Introduction to Python dauert 2 Tage, findet auf Deutsch statt und ist als Connected Classroom geplant. Sie nehmen online teil und arbeiten in Echtzeit mit dem Trainer und der Gruppe. Fragen klären Sie direkt im Kurs, Übungen bearbeiten Sie an Ihrem eigenen Rechner.

Die veröffentlichten Termine laufen jeweils von 09:00 bis 17:00 Uhr deutscher Zeit. Wer lieber vor Ort lernt, kann die Teilnahme über die Räume in München, Nürnberg oder Stuttgart (Partner-Center) anfragen. Was für Ihren Termin möglich ist, bestätigen wir vor der Buchung.

Gibt es eine Prüfung oder ein Zertifikat?

Introduction to Python ist ein Kurs ohne Herstellerzertifizierung und ohne Kurscode. Ein Examen ist nicht im Kurspreis enthalten. Der Kurs vermittelt praktische Grundlagen und ist kein Prüfungsvorbereitungskurs.

Wenn Sie zusätzlich ein Zertifikat für Ihren Lebenslauf anstreben, lohnt der Blick auf zertifizierbare Kurse im Datenbereich, etwa PL-300 Microsoft Power BI Data Analyst oder DP-900 Microsoft Azure Daten Grundlagen.

Python-Kurs mit Bildungsgutschein: Wie funktioniert die Förderung?

Introduction to Python ist für den Bildungsgutschein zugelassen. Ob Sie einen Gutschein erhalten, entscheidet die Agentur für Arbeit bzw. das Jobcenter. Der Ablauf sieht in der Regel so aus:

  1. Sie klären mit uns, ob der Kurs zu Ihrem beruflichen Ziel passt, und erhalten die Kursinformationen für das Gespräch.
  2. Sie sprechen mit Ihrer Ansprechperson bei der Agentur für Arbeit oder dem Jobcenter und begründen, warum Python Ihre Chancen auf eine Stelle verbessert.
  3. Wird der Bildungsgutschein ausgestellt, melden Sie sich damit zum Kurs an.

Ansprechpersonen für Arbeitsuchende in München, Nürnberg und Stuttgart finden Sie auf der Seite IT-Weiterbildung für Arbeitssuchende. Einen Überblick über alle Förderwege gibt die Seite Förderung. Für Beschäftigte kommt eher das Qualifizierungschancengesetz infrage, das Sie mit dem QCG-Fördercheck vorprüfen können. Wie die Förderung speziell bei KI-Themen aussieht, erklärt der Ratgeber KI-Weiterbildung mit Bildungsgutschein oder QCG.

Welcher Kurs passt nach dem Python-Einstieg?

Der nächste Schritt hängt davon ab, was Sie mit Python erreichen wollen.

  • Reporting und Dashboards: PL-300 (3 Tage) vertieft Datenmodellierung und Berichte in Power BI.
  • Datengrundlagen in der Cloud: DP-900 (1 Tag) ordnet relationale und analytische Datenkonzepte in Azure ein.
  • Prozesse ohne viel Code: PL-900 Power Platform Fundamentals zeigt Power Apps, Power Automate, Dataverse und Agents in Copilot Studio.
  • KI beim Programmieren: GitHub Copilot Fundamentals (1 Tag) behandelt, wie Sie Codevorschläge bewerten und produktiv nutzen.
  • KI-Grundbegriffe: AI+ Foundation (1 Tag) erklärt Konzepte, Werkzeuge und ethische Grundlagen moderner KI.

Eine empfohlene Reihenfolge für Daten, Power BI und Python zeigt der Data Analytics Lernpfad. Alle Kurse des Bereichs finden Sie unter Data, Power BI und Python.

Python für Teams: Was gilt für Unternehmen?

Für Fachbereiche, die regelmäßig mit Tabellen, Exporten oder Berichten arbeiten, eignet sich Python auch als Teamtraining. Der Kurs kann als Firmenseminar geplant werden. Vorab stimmen wir Rollen, Teamgröße, Lernziele und eine mögliche Förderung ab. Details dazu finden Sie unter Weiterbildung für Unternehmen.

Nein. Python-Kenntnisse werden nicht vorausgesetzt. Ein grundlegendes technisches Verständnis und Interesse am Programmieren reichen für den Einstieg.

Wie lange dauert Introduction to Python?

Ja, Introduction to Python ist für den Bildungsgutschein zugelassen. Ob Sie einen Gutschein erhalten, entscheidet die Agentur für Arbeit bzw. das Jobcenter.

Ist eine Prüfung im Kurs enthalten?

Nein. Introduction to Python ist ein Kurs ohne Herstellerzertifizierung. Ein Examen ist nicht im Kurspreis enthalten.

Für Berichte und Dashboards ist Power BI mit PL-300 meist der direktere Weg. Python passt besser, wenn Sie Abläufe automatisieren, Daten aufbereiten oder später mit KI-Werkzeugen arbeiten möchten.
