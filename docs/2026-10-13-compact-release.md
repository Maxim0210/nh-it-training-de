# Compact homepage release

- Unified homepage content width (1180px maximum), section spacing and heading scale.
- Shortened the hero and removed mouse-driven motion and decorative glass panes.
- Retained direct links for Arbeitssuchende, Arbeitnehmer and Unternehmen.
- Removed the repeated benefit strip; preserved the Standort anchor on the location section.
- Standardized image proportions and made training-format items compact on mobile.
- Included the tested four-step course finder required by the homepage links.
- Compressed existing hero media to WebP. No video generation or paid services used.

Validation: 360, 390, 768, 1024 and 1440px, stable hero, search button within viewport,
no horizontal overflow, rendered desktop/mobile inspection, six audience customer flows,
dropdown closing, empty-step validation, reset and local link/schema checks passed.
The verification HTML file is intentionally exempt from page metadata requirements.
No form submission was sent. These checks do not establish Google rankings.

Release scope is limited to index.html, styles.css, assets/home-experience.css,
assets/hero-training.webp, weiterbildungs-kompass.html and its two course-finder assets.
Other local copy changes and experimental media remain outside this release.
